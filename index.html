Overview

In this homework, I implemented Bezier curves and surfaces using Casteljau's algorithm, and explored usages of the half-edge data structure. These operations included area-weighted vertex normals, edge flips, edge splits, and Loop subdivision. It was very interesting to explore how powerful the half-edge structure was, and how many applications there are of a relatively simple structure.

Section I: Bezier Curves and Surfaces

Part 1

Given a number of control points, de Casteljau's algorithm interpolates between each set of consecutive points, depending on the parameter t. This process repeats, interpolating between the new points until only one point remains. This final point lies on the Bezier curve. I implemented one step of de Casteljau's algorithm by looping through the control points and evaluating the interpolated point between each consecutive pair using (1 - t) * points[i] + t * points[i + 1].

Part 2

To extend de Casteljau's algorithm to Bezier surfaces, I applied the one-dimensional algorithm twice, once along each parameter direction. Because a Bezier surface is defined by control points on a two-dimensional grid, I first applied the same process as in the one-dimensional case to each row, producing one point per row. I then treated these points as a new set of control points and evaluated them again using the one-dimensional algorithm to obtain the final point on the surface. In my implementation, I repeatedly used evaluateStep until obtaining one point per row, then applied the function again to interpolate across the rows.

Section II: Triangle Meshes and Half-Edge Data Structure

Part 3

To implement area-weighted vertex normals, I iterated through all faces adjacent to a vertex. For each face, I used the cross product of its edge vectors to calculate an area-weighted normal. I then summed these normals and normalized the result to obtain the vertex normal.

The shading is much smoother and more gradual with vertex normals, rather than appearing as individually shaded triangles. Averaging the face normals around each vertex allows the lighting to vary smoothly across the surface.

Part 4

I implemented the edge flip operation by first identifying the six halfedges belonging to the two triangles adjacent to the edge being flipped. I then identified the corresponding faces, vertices, and edges and updated the halfedge pointers to reflect the new diagonal and triangle connectivity.

Initially, I found it confusing to determine how to update the triangles. Drawing the diagram in detail on paper helped considerably. I labeled every halfedge, face, and vertex, which made it much easier to track the pointer changes than trying to reason about the mesh abstractly.

Part 5

To implement the edge split operation, I created six new halfedges and two new faces to represent the split. I calculated the midpoint M using the endpoints of the original edge. I then constructed the four resulting triangles by updating the neighbors of the original and new halfedges.

After working through Part 4, this operation was easier to debug because I could build the new halfedges and faces on top of the diagram I had drawn for the edge flip operation.

Part 6

I implemented Loop subdivision by following the steps in the assignment. Before modifying the mesh, I computed updated positions for existing vertices using Loop subdivision weights and a weighted average of their neighboring vertex positions. I then computed updated edge positions using a weighted average of the edge endpoints and the opposite vertices of the adjacent triangles. After these calculations, I split each original edge and flipped the new edges connecting old and new vertices. Finally, I updated all vertex positions.

Initially, I made an error in the updated vertex calculation for vertices with three neighbors versus the general case, which resulted in a spiky figure. I resolved this by reviewing the Loop subdivision formulas and correcting the weights used for the different vertex degrees.

With repeated subdivision, sharp corners and edges become rounded. As shown below, the cube becomes smoother, and its original edges and corners become less distinct. Pre-splitting selected edges helps preserve more of the original cube shape, although the corners still become somewhat rounded.

The original cube also becomes slightly asymmetric after repeated subdivision. Loop subdivision updates each vertex based on its local neighborhood, so differences in triangulation and connectivity can cause corresponding regions to move differently. Small differences in the mesh can become more noticeable over multiple iterations.

To reduce this asymmetry, I used edge flips to make the triangulation of the cube's faces more symmetric. This changes the local connectivity without introducing additional vertices. The resulting mesh has a more consistent arrangement of edges and triangles across corresponding regions, helping Loop subdivision produce a more symmetric shape.
